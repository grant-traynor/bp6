concurrency.waiting-tasks
Waiting tasks (poe:yield emitted) do not count against the concurrency limit. The agent process exits after yield; no resource is held.

datetime.format
All datetime columns in SQLite use RFC 3339 strings. Do not use Unix timestamps. Rationale: easier to read in raw SQL during development.
